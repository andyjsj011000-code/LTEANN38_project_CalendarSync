# CalendarSync 학교 로그인 전 베타

실제 학교 계정 없이 초대 코드로 참여하는 **로컬 실행형 베타**입니다.
Teams 일정은 가상의 예시이며 실제 학교 공지·기존 Oracle DB와 연결하지 않습니다.

## 실행

1. Python 3.11 이상을 설치합니다. Windows에서는 설치할 때 `Add Python to PATH`를 선택합니다.
2. `CalendarSync_Beta_0.1.1.zip`을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택합니다. ZIP 안에서 바로 실행하지 않습니다.
3. Windows는 `start_beta.cmd`를 실행합니다. macOS·Linux는 터미널에서 `python3 start_beta.py`를 실행합니다.
4. 첫 실행에서는 전용 Python 환경과 의존성을 준비하므로 인터넷이 필요합니다. 이후 같은 폴더에서는 재사용합니다.
5. 실행 창의 `Tester 1`, `Tester 2`, `Tester 3` 중 하나의 코드를 브라우저 로그인 화면에 입력합니다.
6. 자동으로 열리지 않으면 `http://127.0.0.1:8080`을 엽니다. 실행 창을 열어 두고, 종료할 때 Ctrl+C를 누릅니다.

### 실행 파일을 눌렀는데 창이 닫히는 경우

`can't open file ... start_beta.py`가 보이면 같은 폴더의 Python 파일을 찾지 못한 것입니다.
특히 경로에 `Temp`와 `.zip`이 함께 보이면 ZIP 안에서 실행 파일만 연 경우일 수 있습니다.
압축을 푼 폴더에 `start_beta.cmd`, `start_beta.py`, `requirements-beta.txt`, `web_service`가 함께 있는지 확인한 뒤 실행하세요.
이미 Python 경로가 표시되었다면 Python이 실행된 것이므로 이 오류 때문에 Python을 다시 설치할 필요는 없습니다.
0.1.1 실행기는 파일 누락을 먼저 확인하고 원인에 맞는 안내를 표시합니다. 실패 후에는 R로 다시 시도하거나 Q로 닫을 수 있으며, 다른 키를 눌렀다고 창이 닫히지 않습니다.

저장소에서 실행할 때는 `python beta/start_beta.py`를 사용합니다.
다른 앱이 8080 포트를 사용하면 **첫 실행 전에** `python start_beta.py --port 8081`을 사용합니다.
기존 데이터의 주소를 바꾸면 오류로 중단합니다. 같은 포트를 재사용하거나 `--data-dir 다른폴더`로 새 베타를 만듭니다.

## 이번 베타에서 시험할 수 있는 것

- 오늘 할 일: Teams 예시 / 개인 할 일을 나누어 표시
- 개인 할 일 빠른 추가, 자유 제목·메모·날짜·기간·시간 입력, 수정·삭제
- 기간 중 매일 / 선택한 날짜 / 마지막 날만 표시; 마지막 날은 항상 오늘 목록에 포함
- 지난 미완료 항목은 오늘로 옮기지 않고 해당 날짜의 캘린더에서 확인
- 완료 체크는 원래 위치에 취소선·흐린 색으로 유지
- 월간 캘린더: 기간 전체를 이어지는 막대로 표시, 주가 바뀌면 다음 줄로 연결
- 계정별 Teams 채널·일정 종류 표시 설정, 개별 숨김·복원
- 의견 남기기: 해당 베타 서버의 암호화된 DB에 저장

## 범위와 저장 방식

실제 학교 로그인, 실제 Teams 공지 수집·이미지 읽기, 변경 사항 검토, 공통 오류 신고 처리, 브라우저/Teams 알림 발송, Teams 캘린더 등록은 아직 연결하지 않았습니다.
완료한 항목과 취소한 항목이 보이더라도 이 베타에서는 어떤 알림도 발송하지 않습니다.

기본 실행은 실행한 컴퓨터에서만 접속됩니다. **친구 휴대폰에서 접속하는 공유 서버는 이 ZIP으로 자동 배포되지 않습니다.**
각자 ZIP을 실행하면 서로 다른 서버·DB가 만들어집니다. 다른 기기의 동일 계정 사용·실시간 갱신을 테스트하려면 이후 공용 HTTPS 서버에 이 베타를 배포해야 합니다.

`var/data`에 DB, 암호화 키(`config.json`), 초대 코드(`invitations.json`)가 생성됩니다.
키와 DB가 모두 있어야 기록을 다시 읽을 수 있으므로 백업은 이 폴더 전체를 복사합니다.
폴더를 지우면 기록이 사라집니다. 초대 코드는 계정 비밀번호 역할을 하므로 같은 코드를 나누어 쓰면 같은 기록을 보게 됩니다.
공유할 때는 **원본 ZIP**을 전달하고, 실행 후 생성된 `var` 폴더는 포함하지 마세요.

예시 공지 날짜는 DB를 처음 만든 날짜 기준입니다. 시간이 지나면 과거 일정은 캘린더에서 확인할 수 있습니다.
인터넷 연결 없이 앱을 쓰려면 첫 의존성 설치가 완료되어 있어야 합니다.

## 개발·검증

이미 의존성을 설치한 환경: `python beta/start_beta.py --current-python --no-browser`
서버를 띄우지 않고 초기화만 확인: 위 명령에 `--prepare-only`를 추가합니다.
서버 팩토리는 `web_service.beta:create_beta_app`이며, 기존 `web_service.api:create_app`에는 초대 코드 로그인 경로가 없습니다.

Python API 테스트: `python -m pytest tests_web`
JavaScript 범위 배치 테스트: `node tests_web/test_beta_calendar.cjs`
UI 제어 코드 검사: `node tests_web/test_beta_ui.cjs` (DOM·API 대역을 사용하는 검사)
패키지는 `python beta/build_release.py`로 재생성합니다. 실행 중인 데이터·키·초대 코드·가상환경은 포함하지 않습니다.

로컬 운영자는 필요할 때 Python에서 `read_beta_config`, `BetaDatabase`로 자기 서버의 `beta_feedback` 행을 조회하고 `db.unseal(row['body_blob'])`로 의견을 읽을 수 있습니다. 현재 관리 화면은 없습니다.
