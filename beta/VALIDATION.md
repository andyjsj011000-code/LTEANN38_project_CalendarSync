# 베타 검증 기록 · 2026-10-22

- 기존 웹 기반 검사 38개와 베타 API·계정·패키지 검사 11개: 총 49개 통과.
- 실제 FastAPI·HTTPX ASGI 요청과 SQLite를 사용하여 초대 코드 인증, CSRF, 계정 간 접근 차단, 세션 폐기, 호출 제한, 채널·종류 설정, 숨김, 의견 암호화, 기존 DB 거부를 확인.
- 새 폴더에 ZIP을 풀어 `--current-python --prepare-only`로 초기화하고 재실행해 키·초대 코드가 유지되는 것을 확인.
- ZIP 17개 파일을 명시 목록으로 생성하고 CRC, 재빌드 동일성, Windows 배치 파일 줄바꿈을 검사. 실행 데이터·키·초대 코드·가상환경은 제외.
- Node로 JavaScript 문법, 날짜 계산·월 경계·윤년·주간 범위 배치·충돌·표시 날짜 규칙을 검사.
- Node의 DOM/API 대역으로 초기 로그인 화면, 로그인 후 오늘 화면, 문자열 이스케이프, 캘린더·상세 화면, 개인 할 일 저장 요청, 로그아웃 화면 전환을 검사.

현재 실행 환경의 로컬 소켓 제한 때문에 pytest에는 이벤트 루프의 자기 깨우기 소켓만 대체한 외부 실행기를 사용했다. 애플리케이션·DB·테스트 코드는 그대로이며 실제 TCP 서버를 띄운 검증은 아니다.
실제 브라우저 렌더링, 휴대폰 화면, 새 Python 환경의 pip 설치, 사용자의 컴퓨터에서 Uvicorn 실행은 아직 확인하지 않았다.
실제 학교 로그인·Graph·Oracle 운영 DB·알림 발송·공용 HTTPS 배포는 이번 베타 범위에 포함되지 않는다.

수정 대상은 포크의 `oracle` 브랜치다. 기존 일정 동기화 코드·설정 파일은 변경하지 않는다.

## 0.1.1 실행기 수정

사용자 화면의 `Temp/...zip.../start_beta.py: [Errno 2] No such file or directory` 오류에 대응하여, 실행기가 Python 실행 전에 동반 파일 누락부터 확인한다.
ZIP 전체 압축 해제 안내와 Python 명령 누락 안내를 분리하고, 실행 실패 시 임의의 키 입력 대신 R(재시도)/Q(닫기)를 선택하게 변경했다.
관련 검사 3개가 통과했다: 새 ZIP 압축 해제·계정 유지, Windows CMD에서 파일 누락 시 압축 해제 안내, Windows CMD에서 Python이 PATH에 없는 경우 설치 안내.
전체 API 검사는 이전 49개 통과 결과를 유지하며 이번 실행기 변경 후에는 관련 패키지 검사만 실행했다. 실제 GUI 브라우저와 사용자 PC의 설치·서버 실행은 여전히 미검증이다.
