CalendarSync 테스트 서버 개인정보·연동 안내

Microsoft 로그인은 Microsoft 화면에서 처리하며 계정 비밀번호를 웹서비스에 저장하지 않는다. 학교 테넌트·사용자 식별자·프로필, 개인 할 일·표시 설정, 접근 권한이 확인된 채널에서 추출한 일정, 개인 수정과 변경 검토 결과를 서버에 저장한다. 텍스트·프로필·토큰 캐시·푸시 수신 정보는 암호화한다. 조회용 날짜·내부 식별자까지 DB 파일 전체가 암호화되는 것은 아니다.

이 기기 연동 유지를 선택하면 서버에 MSAL 토큰 캐시를 암호화해 보관하고 최대 30일 동안 공지 갱신과 알림을 수행한다. 화면 세션은 별도로 만료된다. 직접 로그아웃하거나 모든 기기 로그아웃을 선택하면 해당 범위의 서버 자격 증명과 알림 등록을 폐기한다. 학교 정책이나 권한 철회로 더 일찍 다시 로그인이 필요할 수 있다. 이번 사용만 로그인은 갱신 캐시를 유지하지 않는다.

direct 모드는 권한이 확인된 Teams 본문, 지원되는 Graph hosted image와 답글을 OpenAI에 전송해 일정을 추출한다. 서버 운영자가 이미지 분석을 끌 수 있다. oracle 모드는 기존 수집 결과를 읽는다. 테스트 운영자는 학교의 기존 처리 범위와 이 사용 목적을 확인하고 참여자에게 고지해야 한다.

브라우저 알림은 사용자가 기기별로 허용할 때만 등록한다. 수신 주소와 암호화 키를 서버에 암호화해 보관한다. 알림 서비스에는 일반적인 일정 확인 안내를 전송하며 잠금화면에 학교 일정 제목·본문은 넣지 않는다. 이미 전송된 알림은 로그아웃 후 도착할 수 있다. 알림 수신은 브라우저·OS 설정과 네트워크의 영향을 받는다.

로그아웃은 개인 할 일·수정 내용·피드백 삭제와 다르다. 개인 데이터의 보관 기간, 삭제 요청 연락처, 백업에서의 삭제 절차는 테스트 운영팀이 실제 공개 전에 확정·안내해야 한다. 소스 분석 캐시는 90일간 갱신되지 않으면 유지보수 작업에서 삭제한다. 보안 기록은 원문 없는 가명 이벤트로 7일 보관한다.

예시 전용 미리보기는 실제 학교 계정·공지·OpenAI·푸시 발송과 연결하지 않는다. 별도의 로컬 예시 DB만 사용한다. 테스트 서버 코드를 준비한 사실만으로 학교의 보안·개인정보 승인이 완료되는 것은 아니다.
