CalendarSync 학교 계정 웹 서비스 개인정보 안내

학교 Microsoft 계정 로그인은 Microsoft의 인증 화면에서 처리한다. 이 웹서비스는 Microsoft 계정 비밀번호를 입력받거나 저장하지 않는다.

서버에 저장하는 정보는 학교 테넌트와 사용자 식별자, 표시 이름과 계정 주소, 본인이 작성한 할 일과 설정, 현재 접근 권한이 확인된 채널의 추출 일정이다. 개인 텍스트와 로그인 접근 토큰은 서버에서 암호화한다. 일정 날짜, 내부 식별자 같은 조회용 메타데이터까지 파일 전체가 암호화되는 것은 아니다.

Teams 접근 토큰은 해당 브라우저 세션에 묶어서 서버에만 저장한다. 갱신 토큰과 offline_access 권한을 요청하지 않는다. 토큰 또는 세션 만료 후에는 다시 로그인해야 한다. 로그아웃하면 해당 세션과 연결 토큰을 삭제하며, 모든 기기 로그아웃은 본인의 모든 세션과 연결 토큰을 삭제한다. Microsoft 전체 계정에서 로그아웃시키는 기능은 아니다.

개인 할 일과 설정은 로그아웃 후에도 유지한다. 삭제 요청은 서비스 운영팀에 전달한다. 운영팀은 배포 전에 정확한 문의 창구와 보관 기간, 탈퇴 시 개인 데이터와 백업 삭제 절차를 고지해야 한다. 이 파일의 존재만으로 학교의 승인이나 개인정보 처리 절차가 완료되었다고 간주하지 않는다.

보안 기록에는 이벤트 종류와 비밀키로 가명 처리한 식별자, 발생 시각만 저장한다. 원문, 이메일 주소, 토큰, 비밀번호, OAuth 인증 코드는 기록하지 않는다. 보안 기록은 7일 뒤 다음 기록 시 정리한다. 요청 제한 기록은 짧은 시간만 유지한다.

기존 수집기가 분석한 Teams 일정은 Oracle에서 읽기 전용으로 가져온다. 이 웹 연결 과정은 새로운 공지 원문을 OpenAI에 전송하지 않는다. 기존 수집기의 OCR·AI 처리에 관한 안내는 운영팀의 기존 개인정보 처리방침을 함께 확인해야 한다.

외부 캘린더 자동 등록, Teams 메시지와 브라우저 알림 전송은 현재 웹서비스에서 제공하지 않는다.
